# 📊 Sales & Orders Analytics Dashboard

An interactive **Excel Sales & Orders Analytics Dashboard** designed to analyze business performance across sales, products, customers, regions, and payment methods.

## 📌 Project Overview

This project transforms raw order data into an interactive Excel dashboard that helps identify important sales trends and business insights.

The dashboard provides a consolidated view of:

* 💰 Total Sales
* 📦 Order & Quantity Performance
* 👥 Customer Analysis
* 🌍 Regional Sales
* 🛍️ Product & Category Performance
* 💳 Payment Method Analysis
* 📅 Sales Trends Over Time

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Formulas
* Data Cleaning & Transformation
* Data Visualization

## 📂 Dataset

The dataset contains order-level information with fields such as:

| Column          | Description                        |
| --------------- | ---------------------------------- |
| `OrderID`       | Unique order identifier            |
| `OrderDate`     | Date on which the order was placed |
| `CustomerID`    | Unique customer identifier         |
| `CustomerName`  | Customer name                      |
| `Region`        | Customer/order region              |
| `ProductID`     | Unique product identifier          |
| `ProductName`   | Product name                       |
| `Category`      | Product category                   |
| `Quantity`      | Number of units ordered            |
| `Price`         | Price per unit                     |
| `TotalAmount`   | Total value of the order           |
| `PaymentMethod` | Payment method used                |

## 📊 Dashboard Features

### 1. Sales Overview

Provides a high-level view of overall sales performance using KPI cards and summary metrics.

### 2. Category Analysis

Analyzes sales across different product categories to understand which categories contribute most to revenue.

### 3. Regional Analysis

Compares sales performance across regions such as:

* East
* West
* North
* South

### 4. Product Analysis

Provides insights into product-level performance and helps identify high-performing products.

### 5. Customer Analysis

Analyzes customer purchasing activity and order contribution.

### 6. Payment Method Analysis

Examines the distribution of sales across payment methods such as:

* UPI
* COD
* Card
* NetBanking

### 7. Time-Based Analysis

Uses order dates to analyze sales trends over time and identify changes in business performance.

### 8. Interactive Slicers

The dashboard includes interactive slicers that allow users to filter the analysis dynamically based on available dimensions such as:

* Region
* Category
* Payment Method
* Date
